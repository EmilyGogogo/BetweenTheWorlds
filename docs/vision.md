# 项目方向与边界

## 现有材料能确认什么

本文件依据 `prototypes/original-play-guide.md` 和原始 Demo 整理。现有材料只有试玩说明与 HTML，没有额外策划稿或美术参考图。下面的定位是从材料中归纳的协作起点，后续可以通过提案修改。

万物之间是一段没有分数、通关目标和强制任务的自然漫游。通过成为草、人、岛屿和星球，让玩家感受尺度、相遇与自身位置的变化。安静、自由探索、低打扰的文字与环境声构成当前体验。

## 第一版体验基线

- 四种尺度可自由移动与观察，通过按钮或 1—4 切换。
- 草可以邀请同类同行；花、石头、树、岛屿和星体在接近时出现有冷却的短句。
- 环境声程序合成；位置与草群只在当前页面会话保留，刷新重置。
- 场景为程序生成，视觉表现仍处原型阶段。减弱动态效果的支持尚不完整。

## 当前协作原则

新增玩法应说明它怎样帮助感受“不同的存在”，并评估是否打断自由探索。先保证基本操作清楚、切换稳定、反馈可信，再扩展世界数量。当前不引入账号、在线服务或付费机制。

## 需要一起决定

| 议题                     | 决策前需要的材料                   |
| ------------------------ | ---------------------------------- |
| 首批目标玩家与支持设备   | 试玩反馈、最低浏览器与硬件样本     |
| 视觉方向与美术完成度     | 有权使用的参考、资源来源、性能测量 |
| 昆虫层或任意实体转换     | 小范围体验原型、交互与规模评估     |
| 存档与持续探索           | 玩家需求、数据格式与迁移方案       |
| 对白风格、哲学表达和音景 | 文案审阅、可用性与听感反馈         |
| 开源许可和首次发布       | 所有者选择、素材授权、发布责任人   |

这些是开放议题，不是已排期需求。提案使用 Issue 模板；采纳后补充任务与决策记录。
