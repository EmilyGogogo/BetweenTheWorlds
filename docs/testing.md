# 验证与试玩

## 自动检查

使用 Node.js 22.13 或更高的 22.x 版本。旧版本需要先升级；`.nvmrc` 指向 22.x，CI 使用该系列的最新版本。

```sh
npm ci
npm run check
npx playwright install chromium
npm run test:e2e
```

Linux 首次安装浏览器可使用 `npx playwright install --with-deps chromium` 补齐系统依赖。`npm run check` 依次检查格式、ESLint、单元与仓库完整性，再生成 `dist/`。浏览器测试直接使用这个发布目录，运行前需要已执行 `npm run build`。

单元与仓库检查覆盖原始附件/第三方文件哈希、文档本地链接、静态服务的资源类型及目录访问边界。浏览器冒烟在 Chromium 中创建真实 WebGL 场景，覆盖进入、移动、同行、对白显示、四层切换、人层 glTF 模型实际加载完成、帮助、声音开关、会话状态保留与刷新重置，并阻止外部资源请求。

冒烟测试在页面加载前暂停 Playwright 时钟，按 50 毫秒一帧推进真实游戏逻辑，对应游戏每帧允许的最大时间步长。移动距离与对白冷却按游戏时间验证，避免软件 WebGL 的低帧率导致实际等待超时；切换期间输入被锁定，直接推进两段淡入淡出定时器并渲染场景。测试不会替换渲染器、设置玩家位置或伪造对白。失败日志包含位置、当前尺度、对白和焦点状态，便于排查 CI 环境差异。

冒烟测试的耗时由软件 WebGL 的栅格速度决定，不由游戏逻辑决定：本地强制 swiftshader 约需 190 秒，核心数更少的 CI 机器更慢。因此单用例预算在 CI 下为 600 秒，本地保持 240 秒，`ci.yml` 的 `timeout-minutes` 必须高于该预算加上安装与构建时间。调整预算不改变任何断言；若耗时持续接近上限，应减少场景的渲染开销或拆分用例，而不是继续抬高预算。

当前自动化不代表所有边界已覆盖：12 株上限、对白的完整冷却时序、镜头拖动/缩放仍需人工验证。浏览器测试使用软件 WebGL，界面视口为 960 × 640 CSS 像素，像素比为 0.5，以减少 CI 的栅格计算量；它不是画质、真实声卡或性能验收，不进行截图比对。未安装 Chromium 时应明确记录未执行，不能当作通过。

## 人工回归清单

记录提交版本、设备、浏览器、窗口大小、系统减弱动态效果设置及执行结果。

- 进入与错误反馈：正常加载可进入；禁用硬件加速或 WebGL 不可用时能理解失败原因。
- 移动与镜头：W/A/S/D、拖动、滚轮正常；失去窗口焦点后不会持续移动。
- 尺度切换：按钮与 1—4 一致；快速切换不会卡在遮罩；各层位置在会话内保留。
- 同行：靠近提示正确；E 邀请、跟随与数量正确；最多 12 株；离开草层再返回不丢失。
- 对白：接近指定实体出现文字和来源说明；有冷却，不连续刷屏。草层的蚂蚁、瓢虫、蜗牛、蛛网与起点附近的大露珠也会回应。
- 草的感受：按 F 出现跟随自己的气泡；靠近未同行的草，它先说一句自己的感受；同行者偶尔开口；气泡不与对白面板同时出现，移出视野时隐藏。
- 天气与感知：约 4 分钟一轮（晴、云影、起风、小雨、雨后）；右侧感知面板的数值随之变化，天气切换时自己会说一句；下雨时天色变灰、有雨丝，雨后湿土变深、蚯蚓出现、露光更亮，高度缓慢增加。
- 草层分布：走到可行走范围的不同方向，花丛、露珠、土块与昆虫应随处可见，远处不应有明显的成片突然出现；三棵巨树位于边缘之外，接近时它们会说话。
- 声音：用户操作后开启；关闭确实静音；切换尺度音景合理；没有音频支持时仍可探索。
- 帮助与键盘：打开/关闭/Escape 正常，文字可读，主要按钮有焦点标识；弹窗完整焦点管理仍是待办。
- 画面与性能：四层无明显渲染错误；不同尺寸下操作入口可见；记录测量数据和卡顿路径。
- 减弱动态效果：检查摆动、旋转与切换，记录当前未遵循偏好的具体行为，不提前声称完全支持。草层在该偏好下停止草叶摆动、昆虫移动和雨丝，天气与光照仍会缓慢变化。
- 刷新：回到欢迎与初始状态；开发版与离线原始 Demo 的基线行为可对照。

## 海湾与 R 功能回归

新增单元回归覆盖实体参数、换身移动、原身体保留、距离与视野限制、涟漪目标稳定、同行成员接管和动物实体身份。四个浏览器用例覆盖原有探索流程、四层 R 直接换身、无选择菜单、岛屿 E、鸟升降与水平移动、鱼下潜与移动、太阳跨层、会话保留和帮助打开时禁用 R。

2026-10-17 本地验证环境：macOS arm64、Node.js 22.23.3、Chrome 155.0.8059.80。feat-island 已同步 main 的 8fcdf0c，保留新版草层的感受、生长和天气；统一每帧 update(dt, time, reduced) 调用，草的生长只作用于原草身体，未配置魂穿参数的环境对白实体不参与 R 候选。`npm run check` 通过，包含格式、lint、13 项单元/仓库/服务器检查与静态构建。`PLAYWRIGHT_CHANNEL=chrome npm run test:e2e` 全部 4 项通过，约 5.2 分钟，使用真实 Chrome 与 SwiftShader 软件 WebGL，未替换渲染器或设置玩家位置。默认仍使用 Playwright Chromium；Chrome 是本机已有浏览器的可选通道，不降低断言。

本地 Chrome / Metal 另外通过真实输入复查：草层拖动视角对准太阳 → R 成为太阳；岛层 R 成为海鸥 → 飞向海岸 → 对准海岸涟漪 → R 进入人层；海鸥接近鱼群 → R 成为鱼 → Shift 下潜。已渲染并检查海湾、鸟、鱼、水下、太阳和阵雨画面；推进真实动画帧确认晴天转阵雨，重新加载减弱动态效果模式后确认保持晴天与静态涟漪，未出现浏览器错误。
