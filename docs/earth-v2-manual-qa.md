**V2 S1–S7 已由用户明确确认通过。** 本表保留为操作与回归参考。 结果见 [V2 QA记录](earth-v2-qa-results.md)。V1 手验已由你明确确认通过；这次只回归新增 Sun 与组合变化，不将旧通过当作 V2 自动通过。

Codex 负责逻辑、模块/API、Node、服务脚本、构建和静态检查；不控制浏览器、不运行 Playwright/E2E、不下载浏览器。你负责实际键鼠、显示、声音和手感。不需测内部距离/相位/颜色数值，不需在控制台改状态或伪造重叠布局。

## 启动与操作约定

1. 在 `BetweenTheWorlds` 项目根目录使用 Node `>=22.13 <23`，运行 `npm run dev`（Windows PowerShell 可用 `npm.cmd run dev`）。未装依赖先 `npm ci`。
2. 打开终端显示的本地地址，默认 `http://127.0.0.1:5173`；端口占用则 `npm run dev -- --port=5174` 并打开 5174。更新代码后刷新，刷新会重置 Moon/Sun 状态。
3. 点击进入，按 4。WASD 移动、拖动观察、滚轮缩放。太阳放在左前方高处；默认镜头下可先尝试 W+A 约 2–3 秒，再看提示微调，不能把固定按键时长当作必达路线。
4. “E 回应光芒”出现后才按 E。没有提示时可能是距离不合格、正在响应或冷却。回到范围内并等提示重新出现再试，不用盯秒表判断精确 3/5 秒边界。

## 不要求日常执行

- 内部 Sun disable/re-enable、3D 数值边界、双资格、精确计时、对象引用/材质数量：Codex 用非浏览器测试验证，不要求你注入状态。
- FPS/GPU/heap 定量分析：仅在明显退化或明确需要数字时另约设备和口径；普通配置性能与可选GC诊断分会话，普通页面没有window.gc/可靠GC读数是预期情况，不要求你配置标志或自动化。没有采样就记“未量化”，不宣称 30 FPS 或无泄漏；不把它作为普通眼检的前置条件。
- 录屏/截图：出现问题或难以描述时提供即可；不用为了填写表格强制录完整试玩。
