# 初始任务清单

下面的编号用于仓库内讨论与认领，不是假定已经创建的 GitHub Issues。状态均为「待讨论」，负责人待认领；优先级表示建议先后，不是排期承诺。认领后把 Issue 链接与负责人回填到本表。

| 编号       | 建议顺序 | 任务与范围                   | 验收标准                                                     |
| ---------- | -------- | ---------------------------- | ------------------------------------------------------------ |
| COLLAB-01  | P0       | 邀请协作者并启用 GitHub 规则 | 两位人类可参与审阅；未批准或检查失败的 PR 被阻止合并         |
| LEGAL-01   | P0       | 确定项目许可与贡献条款       | 所有者记录选择、补充 LICENSE，并核实素材授权                 |
| QA-01      | P0       | 收集桌面试玩基线             | 至少记录不同设备/浏览器的加载、输入、切换与已知问题          |
| A11Y-01    | P1       | 欢迎与帮助弹窗键盘体验       | 焦点进入并保持在弹窗中，关闭返回合理位置；键盘可完成主要操作 |
| A11Y-02    | P1       | 检查减弱动态效果             | 明确持续旋转、摆动、淡入淡出的行为，开启系统偏好后逐项验证   |
| PERF-01    | P1       | 测量四层性能与内存           | 记录设备、帧率、绘制调用、切换后内存和瓶颈，再提出预算       |
| TECH-01    | P1       | 拆出音频与对白控制器         | 保持操作、冷却、会话状态一致；补充针对边界条件的回归         |
| CONTENT-01 | P1       | 整理对白与来源结构           | 原创/改写/引文明确区分，保留当前内容与可访问来源             |
| DESIGN-01  | P1       | 讨论视觉与声音目标           | 提供有授权的参考与可验证目标，经讨论写入决策记录             |
| EXP-01     | P2       | 评估手势或新增尺度           | 先做受限原型，给出设备需求、资源成本和试玩结论               |
| RELEASE-01 | P2       | 准备首次静态发布             | 完成人工回归、许可证确认、发布产物检查和可执行回退步骤       |

大任务拆到可以独立审阅与验证后再认领。涉及共同入口的任务明确依赖，避免同时重写同一文件。完成以验收证据和合并 PR 为准，不以 AI 声称“完成”为准。
