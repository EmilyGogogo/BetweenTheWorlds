# 0002：人层的人物视角与动物观察

- 状态：提议
- 日期：2026-10-17
- 关联任务与参与者：用户在 `feature/human-animal` 分支提出的“增加人类与动物角色”需求；AI 协助实现，待人类审阅

## 问题与约束

人层原本只有一个可移动的人形与两处对白。需求是：多个差异化的人物，各有外形、性格、小习惯、观察侧重、能力、偏好与缺点；第一人称并能看到手和道具，附带第三人称形象预览；多种会自主活动、对靠近的人做出不同反应的小型动物；不同人物观察同一对象时得到不同信息。约束：离线静态运行、不引入框架或在线资源、主控制器不再继续膨胀、重要逻辑可回归测试。

## 考虑的方案

1. 全部写进 `main.js` 与 `human.js`：改动集中，但主控制器继续变大，行为逻辑难以测试。
2. 引入通用实体/组件框架：灵活，但超出当前需要，违背“不为假想需求建框架”。
3. 内容、纯逻辑、渲染、控制分开：文字与数值放 `src/content/`，行为状态机与观察规则放 `src/core/`，模型放 `src/worlds/`，人层交互放 `src/fieldwork.js`，`main.js` 只在少数接口点调用。

## 决定与理由

采用方案 3。动物行为和观察规则不依赖 Three.js，可以直接单元测试；内容集中便于策划和文案审阅；`main.js` 只增加人层分支与接口调用。人物差异用数据描述（`focus`、`traits`、`ability.key`），交互逻辑按这些字段绑定，后续调整平衡不必改控制代码。

人层画面同时调整为清晨稀树草原（伞状金合欢、暖色低角度光），参考了用户在对话中提供的一张氛围图；该图片未提交到仓库，配色属于临时方向，正式视觉目标仍待 DESIGN-01 讨论。

## 影响与验证

- 接口：`main.js` 新增对 `createFieldwork()` 的调用；人层场景状态新增 `cast`、`animals`、`clues`、`fauna`、`animate`、`setTrailGlow`、`sunOffset`，其他层不受影响。
- 资源：人物模型、手部和动物随人层首次进入时创建并常驻，与其他层的缓存策略一致；事件监听在创建时注册一次。
- 回退：删除新增模块并还原 `main.js`、`human.js`、`index.html`、`styles.css` 的对应改动即可回到单一人形。
- 验证：`tests/unit/wildlife.test.mjs`、`tests/unit/observation.test.mjs` 覆盖行为与内容规则；`tests/e2e/human-layer.spec.js` 覆盖第一人称观察、人物切换与跨层保留；动画观感、手部位置与性能需人工试玩记录。
