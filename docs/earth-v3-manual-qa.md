# Earth V3：用户浏览器检查单

**V3代码已实现，非浏览器QA已通过；以下T1–T7现在可测，尚未记为通过。** V1/V2浏览器检查已由你确认通过。Codex负责逻辑、模块/API、实际运动辅助、Node/HTTP/构建检查，不控制浏览器、不运行或新增E2E。对应 [实施分步与QA](earth-v3-implementation-plan.md)。

V3是 **Earth被原有环星球短暂牵引**，不是行星加入并跟随Earth。行星、Sun仍固定；已结伴Moon照旧跟随Earth。不会因为靠近就自动牵引。

## 启动与寻找路线

1. 在 `BetweenTheWorlds` 项目根目录，Node `>=22.13 <23` 下运行 `npm run dev`；Windows PowerShell用 `npm.cmd run dev`。打开终端给出的地址，默认 `http://127.0.0.1:5173`。端口占用则加 `-- --port=5174`，打开5174。首次未安装依赖先 `npm ci`。
2. 代码更新后刷新；进入游戏按4。默认镜头未拖动时，可先按W约4.5–5秒，再A约0.5–0.7秒，松开所有方向键，看“E 感受引力 · 移动即可中止”。这只是初始寻找路线，实际以对象/提示为准，慢设备的游戏秒不等于真实秒。
3. 若提示仍是“回应光芒”，说明Sun当前优先；沿更远的有环星球方向稍向前、保持在圆盘内并松键再看。无需先回应Sun、招募Moon或等随机对白，设计已核算出独立可达区域。
4. 动作时必须松开WASD/箭头。按E后先别动，Earth应缓慢漂移，约2游戏秒内结束；方向输入随时接管。冷却结束、空间仍足够时，提示才再出现。

## T1–T7 必检

| 编号 / 实施步骤                | 你做什么                                                                                                                                            | 通过标准                                                                                                                                                                                         |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **T1｜步骤0/2/3/5，对应V3-M1** | 找到原有环星球，靠近并松键；退开、再靠近。一路不先回应Sun、不邀请Moon也尝试找到行星提示。                                                           | 原四天体都在、无新行星/复制对象；只有距离、静止和空间合格才出现可理解的提示。即使有Moon/Sun高优先级，仍存在直接使用行星动作的地点，不被迫完成前序互动。                                          |
| **T2｜步骤2/5，对应V3-M2**     | 按一次E后不按方向；连按E、长按E；等提示恢复再试一次。                                                                                               | 一次反馈、一次短暂低速漂移和轻微星环回应，约2游戏秒内自行结束；不叠加速度、不反复toast、不带惯性滑行。停止后星环恢复，冷却前不能重开。行星本身不跟着你走。                                       |
| **T3｜步骤1/4，对应V3-M3**     | 分别在牵引中按W/A/S/D、上下左右箭头，包括一次很短的点按；另尝试先按住方向再E，以及E后立刻按方向。                                                   | 任意方向立刻接管，牵引停止、正常38速度移动，无锁键或额外吸力。先方向后E不能启动；E先到则可能已有一次启动信息，但方向接管后不继续拖动。不需要你判断同一帧，精确事件顺序由Codex测试。              |
| **T4｜步骤1/4，对应V3-M4**     | 在有环星球方向向前接近移动边界，松键后看提示；有空间时启动一次，随后反向移动。                                                                      | 到无法继续牵引处无可用提示；活动牵引到边界即停，不越界、不沿边滑行或抖动、无持续吸墙。反向输入正常离开，不需要刷新才能解脱。精确200/12数值由代码测试。                                           |
| **T5｜步骤4，对应V3-M5**       | 三次独立牵引：①立即打开帮助，约5秒后关；②切到其他世界，约10秒后回来；③切去别的窗口再回来。最后刷新一次。                                            | ①/②冻结并在返回后重查空间再继续剩余过程，不补算大段位移；③失焦明确取消，回来不自动继续，需要冷却后重新E。刷新回ready初态。其他世界不被牵引。                                                     |
| **T6｜步骤3/5，对应V3-M6**     | 先邀请Moon，再去行星体验；另在Sun附近和行星附近往返观察提示与光照。拖动、缩放查看位置关系。                                                         | Moon与Earth一起走、不落后一帧式抖动或复制；Sun照明随最终位置自然变化。三动作提示按资格稳定选择，不随机闪换；Sun/Moon原功能仍可用，不因行星状态丢失或重置。                                       |
| **T7｜步骤5/6，对应V3-M7**     | 开系统Reduce Motion/减弱动态并刷新，重新体验牵引/中止；恢复设置刷新。再检查四层按钮/1–4、草招募、声音、帮助/Escape、失焦和约10次往返，探索2–3分钟。 | 减弱动态仍保留你主动请求的低速位移，可随时中止；星环无脉冲/新增旋转，Moon固定偏移随行、Sun无缩放。无额外镜头摇晃，其他模式移动节奏不变、草计数保留、声音可开关，无明显越来越卡或控制台新增红错。 |

不必每次改动都重做全部检查：代码交付会指出需要复测的编号。10次往返、全部8方向等完整回归在首次V3验收或相关输入改动后做；小修只复测受影响项。

## 无需你做的项目

- 三维距离、精确2秒/12单位/6秒、同帧事件顺序、实际预算归属、向量非法值、内部对象启停和引用数量：Codex用非浏览器代码测试完成。
- 不需要传送、在控制台改私有状态、读内部预算或装性能工具来完成日常眼检。
- FPS/GPU/heap定量专项仅在明显退化或确有需求时另测。普通配置性能与可选GC诊断分会话；没有可靠GC接口是预期的未验证情况，不要求暴露window.gc，也不宣称无泄漏。
