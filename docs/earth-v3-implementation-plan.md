## 1. 目标、默认值与 QA 分工

复用有环星球；玩家松开方向键后按E，Earth向其低速牵引，最多2游戏秒/12单位，方向键或失焦可取消。行星自身不跟随Earth，不增加伙伴、主要天体、物理引擎、被动引力、惯性、碰撞或外网能力。

| 项目                | 本轮规划默认值                                                                              |
| ------------------- | ------------------------------------------------------------------------------------------- |
| 既有行星            | Group p在(-150,40,-230)，球半径49，原星环/对白不变；仍不正式命名Saturn                      |
| 主动资格 / 失效距离 | 三维中心距离<=130 / pulling时>160结束；等于160仍可继续                                      |
| 牵引                | 水平朝行星，6单位/游戏秒，最多2秒、实际额外路程预算12                                       |
| 冷却                | 停止后6游戏秒；正常完成可消费本帧余dt，取消/边界/失效帧从完整6秒开始                        |
| 边界                | 参数表中的半径200；启动时1单位探测无需夹取且有效位移>0.05；活动中首次夹取后停止，不沿边滑行 |
| 输入                | 任一WASD/方向键按住即有意图，包括W+S/A+D抵消；keydown锁存中止，不能仅看上一帧moving         |
| 失焦                | blur锁存中止，下次运动阶段不再牵引，冷却后仍需重新E；不改变Moon/Sun原失焦语义               |
| 暂停                | 帮助/欢迎/转场/非活动冻结，回来先重查；对象失效维护可在暂停时清理但不扣冷却                 |
| 主动作优先级        | 可邀请Moon→可回应Sun→可感受有环星球；不存在前序互动解锁                                     |
| 反馈                | 一次toast；仅改变原ring透明度，基线0.8、最大0.95；不旋转星环、不动Sun/大气                  |
| 减弱动态            | E明确请求的低速牵引保留；星环稳定透明度0.88，停止恢复0.8，不增加脉冲或镜头运动              |

普通视觉建议采用 `0.8+0.15×sin(π×elapsed/2)` 的一次包络，从保存的原值计算，不累计叠加。布局/手感参数为待用户检查的起点，不能据数值推断视觉合格。

**Codex执行**：逻辑、模块/API、实际运动辅助与Three.js对象、Node测试、HTTP/构建、格式/lint/链接/原件检查。**用户执行**：[T1–T7检查单](earth-v3-manual-qa.md) 的键鼠、画面、声音及流畅度。Codex不启动/控制浏览器、不运行/新增E2E、不下载浏览器；保留已有E2E/CI与有效断言。每个代码步骤通过再推进；用户项标待验，不因等眼检停止独立代码工作。

可选量化性能用普通、无特殊启动标志的演示浏览器配置，沿用同设备基线，避免DevTools采样开销；可选heap/强制GC诊断必须另开会话，允许诊断启动标志/CDP/DevTools。两者不共用帧率结果。普通页面无window.gc/可靠GC工具是预期情况，记未验证，不用诊断帧率替代正常基线，不要求日常手验先配置工具。Node引用稳定不能写成GPU/heap无泄漏证明。

## 3. 运动契约：先解决顺序和预算归属

下列契约随本轮实施及ADR落地。只扩展当前context，不要求重写 `updateActionContext` 的V1/V2调用方式。

```text
刷新当前context：dt/允许模拟/实时方向键/中止锁存/参数表limit/stepId
  → 原玩家正常移动与原夹取（保存该结果作基点P）
  → world.getMovementInfluence(context, requestBuffer) 或null（纯查询）
  → 共享辅助校验请求、只应用一次并最终夹取
  → movementResult = 最终位置 - P（只归因实际影响）
  → ringedPlanet.update 消费本step反馈/停止/恢复视觉
  → moon.update 一次 → sun.update 一次
  → 原动画/镜头/提示/对白/渲染
```

- 现有提示与E入口的 `refreshActionContext()` 默认dt=0；资格/启动只依据canInteract、实时输入与空间，不要求正dt。只有运动请求/动画/计时要求合法正dt，避免新机制永远看不到提示或按E无效。
- `hasMovementInput`为当前任一方向键按住，独立于净方向和旧w.moving。`movementInterrupted`锁存方向keydown或blur，按事件所属world锁存，直到该world本帧运动和状态处理结束才清除，避免切换前blur被其他层误消费；极短按键在RAF前释放也不能遗漏中止。提示与E执行都读最新值。
- W先到再E：拒绝启动；E先到再W（同一RAF前）：已有一次启动反馈可保留，但第一帧影响前取消，实际牵引为0。不能承诺预知未来输入，不把这一事件顺序测试写成“从未进入pulling”。
- `getMovementInfluence(context,out)`只写调用方复用缓冲 `{x,y:0,z,duration}` 并返回该缓冲/null；不改业务状态/位置/预算/计时。重复查询不叠加。移动键、中止锁存、暂停、失效、无法移动时不请求影响。
- Earth提供实际被共享辅助消费的冻结 `movementInfluenceLimits`（速度6、单次路程12），不在main散落Earth常量。共享辅助验证有限值、y=0、合法duration<=本帧dt、向量长度<=速度×duration且<=单次最大预算；跨帧累计上限由Ring根据真实反馈与剩余预算单独保证，不能仅凭单帧<=12宣称总路程合格；拒绝非法请求、无位移并返回明确原因，不能静默当作成功。
- 局部请求长度=min(6×dt、剩余时长×6、剩余预算)；duration为该请求对应的合法时间，最后一帧截断。合法dt最多0.05；NaN/Infinity/零/负dt不移动、插值或计时。共享正常移动的各层速度/斜向归一化不变。
- 反馈复用缓冲包含 `stepId/accepted/x/z/distance/duration/clamped/blocked/reason`。Ring只消费匹配的、新step反馈一次，且不得消费启动动作之前的旧结果。玩家正常输入及其边界修正不记入牵引预算；pulling缺匹配反馈时安全中止并保留明确诊断，不猜实际位移或spent，也不无限冻结在pulling。
- 若无callback或无请求，影响部分全0；最终位置仍安全夹取。重复处理同step不得重复应用或扣预算。传入旧/无反馈的局部update不施加位移，集成测试必须走生产中的真实移动辅助，不能复制一份公式冒充接线通过。
- ready→pulling→cooldown→ready；elapsed与spent只来自有效步骤。正常完成可将 `dt-duration` 用于6秒冷却；移动/blur/边界/失效等取消帧不扣冷却。浮点时间容差1e-9，路径容差1e-6，不无限补算后台时间。

对象维护：内部显式disable隐藏原p、移除准确的原talker并恢复ring；pulling转完整6秒cooldown，原cooldown保留，ready仍ready。禁用期间冻结该状态，enable复用原对象/记录并保留待完成冷却，不通过重启绕过冷却。意外detach/hidden/引用失配下次活动update清理（暂停也允许），不偷偷重新挂回；显式enable才恢复。Moon/Sun和其余记录不变。
